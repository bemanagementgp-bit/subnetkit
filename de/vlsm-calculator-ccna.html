SubnetKit › VLSM-Rechner für die CCNA

VLSM-Rechner für die CCNA: So funktioniert er

Variable Length Subnet Masking lässt dich einen Adressblock in Subnetze unterschiedlicher Größe aufteilen, damit ein LAN mit 60 Nutzern und eine WAN-Verbindung mit 2 Adressen nicht jeweils ein /24 verbrauchen. Die CCNA prüft die Methode, nicht nur das Ergebnis: das größte zuerst vergeben, jeden Block an seiner Größe ausrichten und Überlappungen vermeiden.

Der VLSM-Tab von SubnetKit macht genau das kostenlos im Browser und zeigt jeden Zwischenwert, damit du deinen eigenen Rechenweg damit abgleichen kannst.

Durchgerechnetes Beispiel: vier Netzwerke aus 192.168.10.0/24

Anforderungen: Vertrieb 60 Hosts, Engineering 28, Verwaltung 12, WAN-Verbindung 2. Nach Größe absteigend sortiert:

  1. Vertrieb, 60 Hosts → /26 (64 Adressen, 62 nutzbar): 192.168.10.0/26, Maske 255.255.255.192, Hosts .1–.62, Broadcast .63
  2. Engineering, 28 → /27 (32, 30 nutzbar): 192.168.10.64/27, Maske 255.255.255.224, Hosts .65–.94, Broadcast .95
  3. Verwaltung, 12 → /28 (16, 14 nutzbar): 192.168.10.96/28, Maske 255.255.255.240, Hosts .97–.110, Broadcast .111
  4. WAN-Verbindung, 2 → /30 (4, 2 nutzbar): 192.168.10.112/30, Maske 255.255.255.252, Hosts .113–.114, Broadcast .115

Insgesamt genutzt: 116 von 256 Adressen; die nächste freie Adresse ist 192.168.10.116, mit Platz für Wachstum. Diese Zeilen sind im Rechner vorbelegt.

So wählst du jedes Präfix

Für einen Bedarf von n Hosts suchst du die kleinste Zweierpotenz, die mindestens n + 2 beträgt (Netzwerk und Broadcast); dann ist das Präfix 32 minus dieser Exponent. Für 28 Hosts: 28 + 2 = 30, die nächste Zweierpotenz ist 32 = 2^5, also ist das Präfix 32 − 5 = /27.

Zwei Regeln bringen Leute ins Stolpern. Erstens muss jeder Block bei einem Vielfachen seiner eigenen Größe beginnen: Nachdem das /26 bei .63 endet, kann ein /27 bei .64 beginnen, weil 64 durch 32 teilbar ist. Zweitens vergibst du in absteigender Größe; würdest du das WAN-/30 zuerst bei .0 platzieren, müsste das /26 bei .64 beginnen und die Lücke wäre verschwendet. SubnetKit zeigt die verschwendeten Adressen pro Zeile, damit du die Kosten jedes Plans siehst.

Häufig gestellte Fragen

Was ist VLSM einfach erklärt?

Unterschiedliche Subnetzmasken innerhalb eines Netzwerks, sodass jedes Subnetz auf seine echte Host-Anzahl zugeschnitten ist, statt jedem Segment dieselbe feste Größe zu geben.

Warum das größte Subnetz zuerst vergeben?

Große Blöcke haben eine strenge Ausrichtung (ein /26 muss bei einem Vielfachen von 64 beginnen). Wenn du sie zuerst platzierst, bleiben die Blöcke zusammenhängend, und es entstehen keine Lücken, die kleine Subnetze sonst hätten füllen können.

Unterstützt der Rechner /31 für Punkt-zu-Punkt-Verbindungen?

Ja. Aktiviere die /31-Option, und jede Anforderung von 2 Hosts wird gemäß RFC 3021 zu einem /31, eine Anforderung von 1 zu einem /32.

Wie viele Netzwerke kann ich kostenlos planen?

In der kostenlosen Version bis zu 5 Anforderungen pro Plan, was typische CCNA-Übungsfragen abdeckt. Pro hebt das Limit für größere Designs auf.
