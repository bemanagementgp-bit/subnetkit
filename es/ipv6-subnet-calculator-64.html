Calculadora de subred IPv6 /64: cómo funciona

La /64 es el tamaño de subred IPv6 estándar para cualquier LAN, segmento inalámbrico o red de máquinas virtuales. Está fijado en 64 bits porque la autoconfiguración de direcciones sin estado (SLAAC) construye la parte de host a partir de un identificador de interfaz de 64 bits; cualquier prefijo más largo que /64 la rompe.

SubnetKit trabaja con todo el espacio de direcciones de 128 bits en tu navegador, sin costo, y la pestaña IPv6 de arriba viene cargada con el prefijo de documentación 2001:db8:abcd:12::/64.

Ejemplo resuelto: 2001:db8:abcd:12::/64

  • Red: 2001:db8:abcd:12::/64
  • Forma expandida: 2001:0db8:abcd:0012:0000:0000:0000:0000
  • Primera dirección: 2001:db8:abcd:12::
  • Última dirección: 2001:db8:abcd:12:ffff:ffff:ffff:ffff
  • Direcciones: 2^64 = 18,446,744,073,709,551,616
  • Tipo: unicast global (2001:db8::/32 está reservado para documentación)

Los primeros cuatro hextetos (64 bits) son el prefijo de enrutamiento y el ID de subred; los últimos cuatro son el identificador de interfaz. Los routers anuncian este prefijo en el enlace y los hosts generan sus propias direcciones, así que nunca te quedas sin direcciones de host en una /64 y no existe el concepto de dirección de broadcast.

Cuántas subredes /64 obtienes

Las asignaciones suelen expresarse por cuántas /64 contienen. Cada 4 bits de prefijo equivalen a un dígito hexadecimal, así que la cuenta es rápida:

  • /48 (sitio empresarial típico): 2^16 = 65,536 subredes /64
  • /56 (asignación residencial común): 2^8 = 256 subredes /64
  • /60 (algunos ISP): 2^4 = 16 subredes /64
  • /32 (asignación de un ISP por parte de un RIR): 2^32 = 4,294,967,296 subredes /64

En SubnetKit, ingresa una /48 o /56 y configura el prefijo de división en 64 para listar las primeras subredes del rango con sus límites. Usa una /127 para enlaces punto a punto entre routers (RFC 6164) y una /128 para loopbacks; todo lo que tenga hosts finales se queda en /64.

Preguntas frecuentes

¿Cuántas direcciones hay en una /64 de IPv6?

2^64, es decir, 18,446,744,073,709,551,616. No hay broadcast ni dirección de red reservada, aunque por convención se evita el identificador de interfaz con todos los bits en cero.

¿Por qué una LAN debe ser /64?

SLAAC obtiene un identificador de interfaz de 64 bits a partir de la dirección MAC o de un valor aleatorio, así que la autoconfiguración solo funciona cuando quedan exactamente 64 bits para la parte de host.

¿Cuántas /64 hay en una /48?

65,536. Los 16 bits entre /48 y /64 forman el ID de subred, que normalmente se escribe como el cuarto hexteto.

¿Puedo usar /127 o /126 en enlaces entre routers?

Sí, la RFC 6164 recomienda /127 para enlaces punto a punto entre routers para evitar ataques de agotamiento de la caché de vecinos. Los segmentos con hosts deberían seguir siendo /64.
