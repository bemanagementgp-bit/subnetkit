¿Qué es el subnetting y cómo funciona CIDR?

Una dirección IPv4 tiene 32 bits y suele escribirse como cuatro octetos decimales, por ejemplo 192.168.1.10. El subnetting divide esos 32 bits en una parte de red (compartida por todos los dispositivos de la subred) y una parte de host (única para cada dispositivo). La notación CIDR (el /26 después de una dirección) indica cuántos bits iniciales pertenecen a la red. Los 32 − 26 = 6 bits restantes identifican hosts, así que el bloque contiene 26 = 64 direcciones.

Dos de esas direcciones están reservadas: la primera (todos los bits de host en 0) es la dirección de red y la última (todos los bits de host en 1) es la dirección de broadcast. Eso deja 64 − 2 = 62 hosts utilizables. Ejemplo resuelto para 192.168.1.70/26:

  1. La máscara para /26 es 255.255.255.192 (binario 11111111.11111111.11111111.11000000).
  2. El tamaño del bloque en el último octeto es 256 − 192 = 64, así que las subredes empiezan en .0, .64, .128 y .192.
  3. 70 cae en el bloque .64: red 192.168.1.64, broadcast 192.168.1.127.
  4. Hosts utilizables: 192.168.1.65 – 192.168.1.126 (62 direcciones).

La calculadora hace exactamente esto con un AND bit a bit entre la dirección y la máscara, y además muestra el resultado en binario para que veas qué bits están fijos.

Máscara de subred vs. máscara wildcard (ACL de Cisco)

Una máscara de subred usa 1 para los bits de red y 0 para los bits de host. Una máscara wildcard es exactamente la inversa: 0 significa "este bit debe coincidir" y 1 significa "ignora este bit". Para /24 la máscara es 255.255.255.0 y la wildcard es 0.0.0.255; para /27 son 255.255.255.224 y 0.0.0.31. Cisco IOS usa máscaras wildcard en las listas de acceso y en las sentencias network de OSPF/EIGRP, por ejemplo access-list 10 permit 192.168.1.0 0.0.0.255 o network 10.1.0.0 0.0.255.255 area 0. La conversión rápida es restar a 255 cada octeto de la máscara de subred; la pestaña IPv4 muestra ambas lado a lado y acepta cualquiera de las dos como entrada.

VLSM paso a paso

Con subnetting de longitud fija, todas las subredes tienen el mismo tamaño, lo que desperdicia espacio cuando un enlace punto a punto solo necesita 2 direcciones pero una /26 le da 64. Las máscaras de subred de longitud variable (VLSM) resuelven esto asignando distintos tamaños desde un mismo bloque:

  1. Lista cada red con la cantidad de hosts que necesita y ordénalas de mayor a menor.
  2. Para cada requisito, elige el bloque más pequeño que contenga hosts + 2 (red y broadcast). 50 hosts → 64 direcciones → /26; 25 → 32 → /27; 10 → 16 → /28; 2 → 4 → /30 (o /31 en enlaces punto a punto, RFC 3021).
  3. Asígnalos uno tras otro a partir de la red base. Como los tamaños son potencias de dos y están ordenados de mayor a menor, cada bloque queda automáticamente alineado con su límite.
  4. Documenta la máscara, el rango y el broadcast de cada subred, y reserva el espacio sobrante para crecer.

La pestaña VLSM ejecuta este algoritmo con el ejemplo de Ventas (50), TI (25), Gerencia (10) y dos enlaces WAN a partir de 192.168.10.0/24, y te dice cuántas direcciones se desperdician y cuánto queda del bloque base.

Fundamentos de IPv6: sin broadcast, /64 en todas partes

Las direcciones IPv6 tienen 128 bits y se escriben como ocho grupos hexadecimales, quitando los ceros a la izquierda y pudiendo contraer una secuencia de grupos en cero a :: (compresión RFC 5952). Los primeros 64 bits identifican la red y los últimos 64 la interfaz. A diferencia de IPv4, no hay dirección de broadcast: IPv6 usa multicast (por ejemplo ff02::1 para todos los nodos del enlace) y no hay direcciones de red/broadcast reservadas, así que todas las direcciones de un prefijo son utilizables. Las LAN usan una /64 para que SLAAC (autoconfiguración sin estado) pueda construir el identificador de interfaz; las organizaciones suelen recibir una /48 (65,536 subredes /64) o una /56. Los enlaces punto a punto suelen numerarse desde una /127. La pestaña IPv6 muestra las formas comprimida y expandida, la red y el tipo de dirección (unicast global, local única fc00::/7, link-local fe80::/10, multicast, documentación 2001:db8::/32 y más).

Consejos para el examen CCNA

  • Encuentra el octeto de interés. Es el octeto donde la máscara no es ni 255 ni 0. El tamaño del bloque es 256 menos ese octeto de la máscara; las subredes empiezan en múltiplos del tamaño del bloque.
  • Cuenta los bits de host, no los de subred. Hosts = 2bits de host − 2. Para preguntas de "cuántas subredes", bits de subred = nuevo prefijo − prefijo original.
  • Recuerda las excepciones. Una /31 tiene 2 direcciones utilizables en enlaces punto a punto y una /32 es una ruta a un solo host; ambas aparecen en configuraciones reales y en preguntas de examen.
  • Conoce los rangos especiales. Privadas RFC 1918 (10/8, 172.16/12, 192.168/16), loopback 127/8, link-local 169.254/16, CGNAT 100.64/10, multicast 224/4 y los bloques de documentación 192.0.2.0/24, 198.51.100.0/24 y 203.0.113.0/24.
  • Practica con VLSM. Los escenarios de examen suelen listar departamentos con su cantidad de hosts; ordénalos de mayor a menor, asigna primero el más grande y verifica que el total quepa en el bloque base.
  • Convierte wildcards al instante. 255 − octeto de la máscara = octeto wildcard. En OSPF también puedes usar la máscara de subred de la interfaz como wildcard (0.0.0.0 para una sola interfaz).

Preguntas frecuentes

¿Cómo calculo una subred?

Escribe la dirección IP y la máscara de subred en binario. La dirección de red es el AND bit a bit de ambas; la dirección de broadcast es la dirección de red con todos los bits de host en 1. Para 192.168.1.10/26, la máscara es 255.255.255.192, la red es 192.168.1.0, el broadcast es 192.168.1.63 y los hosts utilizables van de .1 a .62. La cantidad de direcciones de un bloque es 2 elevado a (32 menos la longitud del prefijo), y los hosts utilizables son esa cantidad menos 2.

¿Cuál es la diferencia entre una máscara de subred y una máscara wildcard?

Una máscara de subred marca los bits de red con 1 (255.255.255.0 para /24). Una máscara wildcard es su inverso bit a bit: los 0 marcan los bits que deben coincidir y los 1 los bits que se ignoran (0.0.0.255 para /24). Los protocolos de enrutamiento como OSPF y EIGRP, y las listas de acceso de Cisco, usan máscaras wildcard. Puedes convertir una en la otra restando cada octeto a 255.

¿Cuántos hosts hay en una /27?

Una /27 tiene 32 direcciones (2 a la quinta) y 30 hosts utilizables, porque una dirección es la de red y otra la de broadcast. Su máscara de subred es 255.255.255.224 y su máscara wildcard es 0.0.0.31. Una /24 se puede dividir en ocho subredes /27.

¿Qué es VLSM?

Las máscaras de subred de longitud variable consisten en dividir una red en subredes de distintos tamaños en lugar de bloques iguales, para que cada departamento o enlace reciba una subred acorde a su cantidad de hosts. Ordena los requisitos de mayor a menor, dale a cada uno el bloque más pequeño que alcance para sus hosts más las direcciones de red y broadcast, y asígnalos uno tras otro a partir de la red base. La pestaña VLSM lo automatiza e informa las direcciones desperdiciadas y la eficiencia.

¿IPv6 tiene dirección de broadcast?

No. IPv6 reemplazó el broadcast por grupos multicast como ff02::1 (todos los nodos del enlace). Como no hay broadcast ni dirección de red reservada en el mismo sentido, todas las direcciones de un prefijo IPv6 son utilizables. Las LAN estándar usan una /64 para que funcione la autoconfiguración de direcciones sin estado (SLAAC), y los sitios suelen recibir una /48 o /56 de su proveedor.
