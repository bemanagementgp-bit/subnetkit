Calculateur de masque générique : comment ça marche

Les listes d'accès Cisco et les instructions network d'OSPF et d'EIGRP prennent un masque générique plutôt qu'un masque de sous-réseau. Un bit à 0 signifie « doit correspondre », un bit à 1 signifie « ignorer » : le masque générique est donc simplement l'inverse bit à bit du masque de sous-réseau, soit 255.255.255.255 moins le masque, octet par octet.

SubnetKit affiche le masque générique à côté du masque de sous-réseau pour chaque calcul, et sa saisie libre accepte la syntaxe address wildcard directement depuis une configuration IOS. C'est gratuit et cela fonctionne dans le navigateur.

Exemple commenté : 172.16.32.0/20

  • Masque de sous-réseau : 255.255.240.0
  • Masque générique : 0.0.15.255 (255 − 255 = 0, 255 − 255 = 0, 255 − 240 = 15, 255 − 0 = 255)
  • Plage d'adresses couverte : 172.16.32.0 – 172.16.47.255 (4 096 adresses)

Le même bloc en syntaxe IOS :

  • access-list 10 permit 172.16.32.0 0.0.15.255
  • router ospf 1 puis network 172.16.32.0 0.0.15.255 area 0

Pour correspondre à un seul hôte, utilisez le masque générique 0.0.0.0, ou le mot-clé host ; pour tout faire correspondre, utilisez 0.0.0.0 255.255.255.255, ou any. Collez 172.16.32.0 0.0.15.255 dans le champ de saisie rapide de SubnetKit et il est interprété automatiquement comme un /20.

Référence : préfixe, masque et masque générique

  • /8 255.0.0.0 → 0.255.255.255
  • /16 255.255.0.0 → 0.0.255.255
  • /20 255.255.240.0 → 0.0.15.255
  • /24 255.255.255.0 → 0.0.0.255
  • /25 255.255.255.128 → 0.0.0.127
  • /26 255.255.255.192 → 0.0.0.63
  • /27 255.255.255.224 → 0.0.0.31
  • /28 255.255.255.240 → 0.0.0.15
  • /30 255.255.255.252 → 0.0.0.3
  • /32 255.255.255.255 → 0.0.0.0

Les masques génériques ne se limitent pas à des 1 contigus. Dans une ACL, 0.0.1.0 correspondrait à tous les troisièmes octets pairs ou impairs, une astuce parfois utilisée pour viser des sous-réseaux alternés en une seule ligne. Ces masques non contigus sont valides dans les ACL mais pas dans OSPF.

Questions fréquentes

Comment calculer un masque générique ?

Soustrayez chaque octet du masque de sous-réseau de 255. Pour 255.255.255.192, le résultat est 0.0.0.63.

Un masque générique est-il la même chose qu'un masque inverse ?

Oui. La documentation Cisco utilise les deux termes pour désigner le complément bit à bit du masque de sous-réseau.

Pourquoi OSPF utilise-t-il des masques génériques ?

L'instruction network réutilisait à l'origine la logique de correspondance des ACL, qui teste les bits d'adresse de façon sélective. Les versions modernes d'IOS acceptent aussi un masque de sous-réseau ici et le convertissent, mais les examens attendent toujours la forme générique.

Quel masque générique correspond à un seul hôte ?

0.0.0.0, ce qui signifie que chaque bit doit correspondre. Dans les ACL, vous pouvez écrire host 10.1.1.5 au lieu de 10.1.1.5 0.0.0.0.
